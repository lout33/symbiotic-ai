# COMMITMENTS.md - Said vs Did

> Optional, but high leverage. Use this when you want the agent to track what you said you would do against what actually happened.

## How to Use It

- Log explicit commitments, not every possible task
- Good fit: "I'll post this tomorrow", "I'll send that message tonight", "I'll apply today"
- Bad fit: vague backlog items with no real promise attached
- Review misses for patterns, not self-punishment
